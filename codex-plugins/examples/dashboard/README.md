# X 账号数据看板（示例数据）

这是一份可在原有本地 Dashboard 编辑器中修改的正式示例，视觉参考仓库 README 的数据看板截图。所有指标来自 `src/x-account-daily.csv`，数据为确定性合成数据，不代表用户或任何真实账号。

页面包含近 28 天的五项 KPI 与前 28 天对比、365 天的日值灰柱和蓝色 7 日均线、最近 90 天互动率和净增关注者走势，以及可排序的逐日数据表。统计截止日期和年度趋势指标均可切换。原编辑器的 Comments 和 Sources 保持原位置，页面不添加浮窗。

运行真实工具生成或刷新示例：

```powershell
node codex-plugins/examples/dashboard/create-showcase.mjs
```

生成器通过现有 CLI 的 `upload`、`write-db` 和 `check` 写入编辑器存储，不直接编写 `db/`。重新运行会替换本示例的六个已知文档；需要保留手工修改时先复制整个示例文件夹。

`src/index.html`、`src/dashboard.css` 和 `src/dashboard.js` 是可编辑源文件。源文件变化后重新运行生成器才会更新编辑器存储；编辑器中的手工修改则保存到 `db/`。数据与计算规则可在 Sources 中查看：`daily` 是原始 CSV，`trend` 是每日值和 7 日均线，`periods` 是所有可用截止日的 28 天对比。

`verification.json` 保存源数据哈希、日期连续性、原始组成项核对、实际页面计算函数与独立汇总结果比对、配色校验和 CLI 结构检查结果。该生成脚本不会启动服务器、模型或评论队列；浏览器视觉和交互验收需在打开编辑器后执行。

样例固定在 2025-11-01 至 2026-10-31，共 365 天。默认统计期为 2026-10-04 至 2026-10-31，对比期为 2026-09-06 至 2026-10-03。7 日均线从数据的第七天开始，区间互动率使用总互动数除以总曝光量，不是每日互动率的简单平均。
