Nimbus 是一款轻声说天气的产品。用短句传递可采取行动的信息：先说温度，再说接下来的变化。写“18°，小雨将在午前渐歇”，不写“糟糕天气来袭！”。不用感叹号，不用装饰 emoji；只有真实预警才使用警示语气。本展示中的城市、温度与预报为组件示例数据，不代表实时天气。

## 颜色：让天空有层次

将页面放在 `surface`，卡片放在 `surface-raised`。正文用 `ink`，体感、湿度和更新时间用 `ink-muted`。在这两种表面上，文字保持清晰、留白保持充分。用 `sky` 表达唯一主操作和选中状态，填充上的文字用 `on-sky`；深色主题不能沿用白色按钮文字。

将次要选中区域放在 `sky-soft`，配 `ink` 或 `sky-strong`。`haze` 与 `line` 只用于云带和装饰分隔，不单独承担控件边界；可操作边界用 `control-border`。降水图形用 `rain`。阳光的 `sun` 是少量点缀，文字放在其上时使用 `on-sun`。

天气预警使用 `warning-soft` 背景与 `warning` 文字，并明确写出“天气预警”；状态不能只靠颜色表达。使用 `clear` 时同时写出“雨已停”等状态文字。

## 字体：数字优先，说明轻声

使用 `sans` 系统字体栈，离线也能完整显示中英文。品牌名始终写作 **Nimbus**。封面使用 `display`；每个天气视图只出现一次 `reading` 温度数字。城市名使用 `title`，区块标题用 `heading`，短摘要用 `body`，操作用 `label`，更新时间和辅助数据用 `caption`。不要给每一个数字都加粗，也不要把中文正文压成紧密行距。

## 空间与形状

沿 4px 网格排布。图标间隔用 `space-1` 或 `space-2`，关联信息用 `space-3`，标准天气卡片内边距用 `space-6`，主要区块间隔用 `space-8`。天气卡片使用 `radius-lg` 与 `shadow-card`；操作和切换控件使用 `radius-full`。只给浮动层使用 `shadow-float`，不要在同一张卡片上叠加多层阴影。

## 操作与可访问性

每个视图最多一个主按钮。主按钮使用 `sky` 与 `on-sky`；安静操作使用可见边界。按钮至少 44px 高。键盘焦点使用 `focus-ring`，保留表面间隙和实色外圈。禁用状态同时禁用真实交互，不能只有视觉变浅。

切换今天、明天和七天时，始终显示当前选择文字，使用 `aria-pressed` 表达选中状态。天气卡片的温标按钮应同时转换当前温度、体感、最高与最低温，不能只替换单位符号。

## 图形与标志

用宽天空块、胶囊与半圆云带组织品牌图形，使用 `sky`、`haze`、`sky-strong` 与 `ink`。几何建立在间距与圆角尺度上；图形不能压过品牌名。标志是 `assets/Logos/nimbus-mark.svg`，固定使用浅色主题的 `sky` 墨色；它通过图片加载，不继承文字颜色。图标仅用于天气信息和真实操作，不用作段落装饰。

## 使用组件

组件通过 `components/bundle.js` 暴露为 `window.Nimbus`，依赖编辑器已提供的 React 18 与 ReactDOM。消费时先加载当前主题的 tokens、`components/bundle.css`，再加载组件脚本；系统字体无需下载文件。颜色、间距、圆角与字体的唯一源为 `tokens.json`，不要在消费页重定义同名变量。

- `Nimbus.Button`：调用方提供动作名称与 `onClick`；用 `variant="primary"` 表达主操作。
- `Nimbus.WeatherCard`：调用方提供城市、摄氏温度和天气摘要；温标切换由组件管理。
- `Nimbus.ForecastSwitch`：调用方提供 `value` 与 `onChange` 来驱动对应预报内容；不提供 `value` 时可独立使用。
